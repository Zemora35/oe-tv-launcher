# O.E tv branding

The public-facing launcher name is `O.E tv`. The home header puts the
`Oğuzhan Eklidağ` signature below the brand; the accessible description preserves
the exact Unicode spelling. Brand names are deliberately not translated or
mirrored in RTL. The original GPL license, upstream credits, package identity and
Gradle variant names are unchanged.

`native-launcher/app/src/main/res/drawable-xxxhdpi/oguzhan_eklidag_signature.png`
is a static transparent white-ink signature generated with the built-in imagegen
tool, using the user's supplied handwriting as the style reference. Android
density-scales the resource; no downloaded font, blur or continuous animation is
needed. The original attachment is not packaged or added to Git.

Final image-edit prompt:

> Clean this signature asset for production UI. Preserve the exact cursive name
> Oğuzhan Eklidağ and Turkish diacritics. Remove ALL speckled noise, splatter,
> grain, fringe, duplicated edges and background. Only smooth solid white
> handwritten ink strokes with antialiased edges on fully transparent canvas.
> Simple pen-calligraphy, moderate stroke width legible at small header size,
> no shadows no textures. Tightly frame the signature horizontally with just
> 3 percent transparent margins around its bounds, not a big empty canvas.
> One signature.
